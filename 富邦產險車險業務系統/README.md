# 富邦產險車險業務智能系統

## 📋 系統說明

這是專為富邦產險業務員設計的完整業務輔助系統，涵蓋客戶開發到成交的全流程：

### 五大核心功能

| 功能 | 說明 |
|------|------|
| 👤 **客戶資料** | 基本資料、車輛資料、產險資料、電動車專屬欄位 |
| 📋 **出險紀錄** | 查詢/新增出險、風險評級、NCD計算 |
| ⚖️ **保單比較** | 既有保單 vs 富邦方案、試算比較、詳細表格 |
| 🧮 **保費試算** | 智能試算、圖表分析、報價單列印 |
| 📊 **分析報告** | 風險分析、趨勢圖表、業務建議 |

---

## 🎯 核心特色

### ⚡ 電動車專屬模組
```
自動顯示 EV 專屬欄位：
├── 電池容量 (kWh)
├── 充電方式（家用/公共/兩者）
└── 家用充電樁安裝狀況
```

### 📊 智能風險評估
- **出險查詢**：手動新增或系統查詢（模擬）
- **風險分級**：低/中/高風險自動判定
- **NCD 建議**：自動計算無賠款折扣係數

### 💰 保單比較系統
```
三欄比較設計：
├── 🟠 現行保單（他公司）
├── 🔵 富邦方案（推薦）
└── 📊 比較摘要（差額計算）
```

### 📈 圖表分析
- **保費構成圖**：圓餅圖顯示各險種佔比
- **出險趨勢圖**：折線圖顯示歷年出險走勢
- **理賠類型圖**：長條圖顯示事故類型分布

## 🚀 使用流程

### Step 1: 建立客戶資料
1. 填寫基本資料（姓名、身份證、電話）
2. 選擇保險類型（車險/產險/都要）
3. 填寫車輛資料（油車/Hybrid/電動車/機車）
4. 電動車自動顯示電池/充電欄位
5. 點擊「儲存客戶資料」

### Step 2: 查詢出險紀錄
1. 輸入身份證/車牌查詢
2. 或手動新增歷史出險
3. 系統自動計算風險等級與 NCD

### Step 3: 保單比較
1. 選擇現行保險公司
2. 輸入現行保費
3. 選擇富邦推薦方案
4. 查看差額與詳細比較表

### Step 4: 保費試算
1. 選擇方案等級（基本/標準/尊榮）
2. 確認 NCD 係數
3. 產生試算結果與圖表
4. 列印報價單給客戶

### Step 5: 產生報告
1. 選擇報告期間（1年/3年/5年）
2. 查看風險分析與趨勢圖
3. 取得業務建議

### 電動車銷售話術
```
「您的電動車電池佔車價約40-60%，
 一般車體險不包含電池故障，
 富邦電動車專屬方案提供：
 ✓ 電池/馬達獨立保障
 ✓ 充電設備損失險

 ✓ 涉水短路特別保障」
```

### NCD 無賠款說明
```
「無賠款折扣(NCD)是獎勵安全駕駛的制度：
 • 連續3年無理賴 → 0.38（省62%）
 • 連續2年無理賴 → 0.44（省56%）
 • 連續1年無理賴 → 0.50（省50%）
 出險次數越多，係數越高，保費越貴」
```

### 比較表使用時機
```
1. 客戶有他公司報價時
2. 續保客戶想要比較時
3. 展示富邦保障優勢時
4. 強調CP值時
```

## 📝 注意事項

1. **資料安全**
   - 客戶身份證字號為敏感資料
   - 建議部署在內網或加密環境
   - 定期備份客戶資料

2. **出險查詢**
   - 目前為模擬查詢功能
   - 實際需串接保險公會或公司API

3. **試算基準**
   - 保費為示意計算
   - 實際保費以公司核保為準

4. **列印功能**
   - 報價單可直接列印
   - 建議使用 A4 紙張
