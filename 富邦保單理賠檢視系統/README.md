# 富邦保單理賠智能檢視系統

## 📋 系統說明

這是專為保戶設計的理賠輔助系統，讓客戶在事故發生後能快速：
1. 上傳保單或輸入保單資訊
2. 描述事故經過
3. 獲得理賠可行性分析
4. 取得完整的文件清單與指引

---

## 🎯 核心功能

### 三步驟完成理賠檢視

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  步驟 1     │ →  │  步驟 2     │ →  │  步驟 3     │
│  上傳保單   │    │  描述事件   │    │  取得指引   │
└─────────────┘    └─────────────┘    └─────────────┘
```

---

## 📱 功能詳細說明

### 步驟 1：上傳保單

**支援格式：**
- PDF 檔案
- JPG / PNG 圖片
- 或直接手動輸入保單資訊

**擷取資訊：**
- 保單號碼
- 險種類型（醫療/意外/壽險/癌症/車險等）
- 投保日期
- 保額內容

---

### 步驟 2：描述事件

**事件類型選擇：**

| 類型 | 適用情境 | 檢查重點 |
|------|----------|----------|
| 🏥 疾病就醫 | 一般疾病住院/門診 | 等待期、疾病定義 |
| 🚑 意外傷害 | 交通事故、跌倒等 | 意外定義、事故證明 |
| 🛏️ 住院手術 | 需要手術治療 | 手術定義、住院天數 |
| ⚠️ 重大疾病 | 癌症、中風、心肌梗塞 | 疾病定義、診斷標準 |

**填寫項目：**
- 事件描述（時間、經過、目前狀況）
- 就醫醫院
- 發生日期
- 預估醫療費用（可選）

---

### 步驟 3：理賠分析結果

#### 📊 理賠可行性分析
```
✓ 有效保單
✓ 事故認定：意外傷害
✓ 適用條款：意外身故/失能、意外醫療
✓ 理賠可能性：高（資料齊全可申請）
```

#### 💰 預估理賠金額
```
$30,000 - $80,000
（實際金額以核保結果為準）

明細：
├── 意外醫療給付：$20,000 - $50,000
├── 住院日額（3天）：$3,000 - $6,000
├── 骨折給付：$7,000 - $14,000
└── 手術慰問金：$0 - $10,000
```

#### ⚠️ 重要提醒
- 請於事故發生後 5 日內盡快通知保險公司
- 保留所有醫療單據正本
- 若為交通事故，請務必報警取得事故證明
- 診斷證明書請醫師加註「意外傷害」字樣

## 📋 文件清單系統

### 文件分類標籤

| 標籤 | 顏色 | 說明 |
|------|------|------|
| **必填** | 🔴 紅色 | 缺少將無法受理 |
| **如有...** | 🟡 黃色 | 特定情況才需要 |
| **建議** | 🟢 綠色 | 建議準備以加速流程 |

### 標準文件清單

#### 必填文件
1. **理賠申請書**
   - 請填寫完整並親自簽名
   - 💡 可至富邦官網下載或向業務員索取

2. **身分證正反面影本**
   - 請確認影本清晰可辨識

3. **診斷證明書/醫療證明**
   - 需載明疾病/傷害原因、治療期間
   - ⚠️ 請醫師加註「意外傷害」字樣（如為意外事故）

4. **醫療費用收據正本**
   - 需加蓋醫院收據章
   - 💡 若收據遺失，請醫院補開證明

#### 如有住院
- **住院/手術證明**
  - 出院證明或手術紀錄

#### 如為交通事故
- **交通事故證明**
  - 警察事故登記表或和解書
  - ⚠️ 交通事故務必報警處理，取得證明文件

#### 如有骨折/重大傷害
- **X光/檢查報告**
  - 骨折部位X光片或相關檢查報告

#### 建議準備
- **存摺封面影本**
  - 用於理賠金轉帳
  - 💡 若無提供，理賠金將以支票給付

## 🏥 就醫注意事項

### 請醫師於診斷證明書載明：

```
□ 事故發生日期與時間
□ 事故原因（如：交通事故、跌倒、疾病等）
□ 傷害部位與程度（如：右側橈骨骨折）
□ 治療方式（門診/住院/手術）
□ 治療期間（起訖日期）
□ 是否需後續治療或復健
```

**💡 小提示：**
告知醫師「這份診斷證明書要用於保險理賠」，醫師會知道如何開立

## 📍 理賠申請流程

```
1. 準備文件
   └─ 依照清單準備所有應備文件

2. 提交申請
   ├─ 富邦官網線上申請
   ├─ 富邦人壽APP
   ├─ 郵寄至就近服務中心
   └─ 交由業務員代辦

3. 案件審核
   ├─ 一般案件：5-7 個工作天
   └─ 複雜案件：10-14 個工作天

4. 理賠給付
   └─ 轉入指定帳戶或以支票寄送
```

## ❓ 常見問題

**Q: 醫療收據遺失可以補辦嗎？**
> A: 可以。請攜帶身分證至醫院掛號櫃台申請「收據補發」或「繳費證明」，部分醫院會收取工本費。

**Q: 診斷證明書沒寫「意外」會影響理賠嗎？**
> A: 會。意外險理賠必須證明事故為「外來、突發、非疾病」引起，請回診請醫師加註或重新開立。

**Q: 可以請家人代辦理賠嗎？**
> A: 可以。需附上身故/失能者及代辦人身分證影本，並填寫委託書。

**Q: 多久會收到理賠金？**
> A: 文件齊全的一般案件約 5-7 個工作天；複雜案件或需補件者約 10-14 個工作天。

## 📝 注意事項

1. **資料安全**
   - 客戶上傳的保單及醫療資訊為敏感資料
   - 建議部署在 HTTPS 環境
   - 考慮資料加密儲存

2. **理賠說明免責**
   - 預估金額僅供參考
   - 實際理賠以公司核保結果為準
   - 建議加註「本系統僅供參考，不保證理賠結果」

3. **醫療資料隱私**
   - 符合個資法規範
   - 取得客戶同意後處理醫療資訊
