# 富邦產險車險智能推薦系統

## 📋 系統說明

這是專為富邦產險設計的智能推薦系統，涵蓋：
- 🚗 **汽車保險（車險）** - 包含油車、油電混合車、電動車(EV)、機車
- 🏠 **產物保險（產險）** - 住宅、動產、責任、意外等

特別針對 **電動車(EV)** 和 **油電混合車** 設計專屬保障方案！

---

## 🎯 核心特色

### 智能分類
```
Q1: 險種類型選擇
├── 🚗 純車險 → 跳過產險問題（2-4題）
├── 🏠 純產險 → 跳過車險問題（直接到Q5）
└── 🔄 兩種都要 → 完整問卷
```

### 電動車專屬保障 ⚡
- **電池/馬達專屬條款** - 電池佔車價40-60%，需獨立保障
- **充電設備險** - 家用充電樁/公共充電設備損失
- **電動車專屬拖吊** - 平板拖吊避免底盤電池損壞
- **涉水短路保障** - 電動車特殊風險

## 🚗 車險推薦邏輯

### 電動車專屬方案 ⚡
```
必保項目：
├── 強制汽車責任險（法定）
├── 電動車專屬車體險
│   ├── 電池損壞/故障保障
│   ├── 馬達控制系統保障
│   └── 涉水短路保障
├── 充電設備損失險
│   ├── 家用充電樁
│   └── 公共充電設備責任
└── 電動車專屬道路救援（平板拖吊）
```

### 油電混合車方案 🔋
```
基本保障 + 電池/馬達保障
├── 傳統車體險（甲/乙/丙式）
├── 電池模組附加條款
└── 動力系統綜合保障
```

### 汽油/柴油車方案 ⛽
```
依車齡建議：
├── 新車（0-1年）→ 甲式車體險（全險）
├── 近新車（1-3年）→ 乙式車體險
├── 中齡車（3-7年）→ 丙式車體險或限額車體
└── 老車（7年+）→ 第三人責任險為主
```

## 🏠 產險推薦項目

### 住宅保障
- **住宅火災及地震基本險** - 法定基本保障
- **擴大地震險** - 台灣地震頻繁建議加保
- **超額地震險** - 高價值住宅適用
- **住宅動產綜合險** - 家具電器保障

### 個人保障
- **個人責任險** - 過失造成他人損害
- **個人意外傷害險** - 24小時意外保障
- **旅遊不便險** - 出國必備
- **行動裝置險** - 手機/平板保障
- **寵物險** - 毛小孩醫療保障

## 🚀 部署步驟

### Step 1: 建立 Google 表單

1. 前往 [Google Forms](https://forms.google.com)
2. 建立新表單：「富邦產險車險智能推薦 - 客戶資料」
3. 新增欄位：

| 欄位名稱 | 類型 | 說明 |
|----------|------|------|
| 姓名 | 簡答 | 客戶姓名 |
| 電話 | 簡答 | 聯絡電話 |
| Email | 簡答 | 電子郵件 |
| 險種類型 | 單選 | auto/property/both |
| 車輛類型 | 單選 | gasoline/hybrid/electric/motorcycle |
| 預算等級 | 單選 | economy/standard/premium |
| 產險項目 | 核取方塊 | home/content/liability... |
| 保障需求 | 核取方塊 | theft/damage/earthquake... |
| 聯絡時間 | 單選 | morning/afternoon/evening |

## 📝 注意事項

1. **法規遵循**
   - 強制險為法定必保
   - 個資收集需符合個資法
   - 問卷需加免責聲明

2. **電動車特殊提醒**
   - 電動車電池維修費用高昂
   - 拖吊需使用平板拖車
   - 充電設備需獨立投保

3. **資料安全**
   - Google Form 設為「限知道連結者」
   - 定期備份客戶資料
